# Как менять контент DamuMarket

Сайт — это статика без админки. Всё, что нужно — открыть пару текстовых файлов и поправить. Не нужно знать программирование, просто аккуратно работайте с символами `<...>`.

## Где что лежит

| Что меняем | Файл | Раздел внутри файла |
|---|---|---|
| Телефон / WhatsApp | `index.html` + `script.js` | искать `+7 700 215 2893` и `WA_PHONE = '77002152893'` |
| Адрес магазина | `index.html` | искать `Васнецова, 43` |
| Часы работы | `index.html` | блок `dt: Часы работы` |
| Категории (название/описание) | `index.html` | блок `<!-- CATEGORIES -->` |
| Бренды | `index.html` | блок `<!-- BRANDS -->` |
| Хиты продаж | `index.html` | блок `<!-- FEATURED -->` |
| Отзывы | `index.html` | блок `<!-- REVIEWS -->` |
| Ссылка на 2ГИС | `index.html` | искать `2gis.kz/almaty/geo/...` |
| Картинки категорий | `assets/categories/*.svg` | подменить файлы (см. `IMAGES.md`) |

## Поменять телефон

1. В `index.html` через Find&Replace замените `+7 700 215 2893` на новый номер (с пробелами для отображения).
2. В `index.html` замените `tel:+77002152893` на `tel:+<новый_номер_без_пробелов>`.
3. В `script.js` замените `WA_PHONE = '77002152893'` на ваш номер **без `+` и пробелов** (например `'77001234567'`).

## Поменять адрес

Через Find&Replace замените `Васнецова, 43` на новый адрес. Также обновите ссылку на 2ГИС (4 места: hero-iframe, кнопка карты, ссылка отзывы→2ГИС, ссылка в футере).

## Добавить новую категорию

Скопируйте блок одной `<article class="cat-card">…</article>` в `index.html`, измените:
- `<img src="assets/categories/НОВАЯ.svg" alt="…">` — путь к картинке,
- `<h3>Название</h3>`,
- `<p>Описание</p>`,
- `data-wa-text="Здравствуйте! Интересует …"` — текст, который автоматически попадает в WhatsApp.

Картинку либо нарисуйте/возьмите, либо используйте любую существующую SVG-заглушку.

## Поменять «Хит продаж»

В блоке `<!-- FEATURED -->` поправьте 4 карточки `<article class="prod-card">`. Принцип такой же, как у категорий.

## Поменять отзывы

В блоке `<!-- REVIEWS -->` в каждой `<article class="review-card">` редактируется `<p>текст</p>` и `<footer><strong>Имя</strong> · должность</footer>`.

## Опубликовать обновление

После правок:
1. Закоммитьте файлы (через GitHub Desktop / `git`).
2. Запушьте на GitHub.
3. GitHub Pages автоматически пересоберёт сайт через 1–2 минуты.

Если используете веб-интерфейс GitHub: открыли файл → карандашик → правите → «Commit changes».
