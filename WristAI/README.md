# WristAI — голосовой ИИ-ассистент для Apple Watch

Самостоятельное (watch-only) приложение для Apple Watch: надиктовываешь вопрос голосом — нейронка отвечает текстом **и голосом**. iPhone-приложение не требуется, всё работает прямо на часах.

## Как это работает

1. Нажимаешь кнопку микрофона и говоришь — запись идёт с микрофона часов (файл `.m4a`).
2. Запись отправляется в **Whisper** (распознавание речи) через бесплатный API [Groq](https://groq.com) — отлично понимает русский.
3. Распознанный текст уходит в LLM (по умолчанию **Llama 3.3 70B** на Groq — быстрая и бесплатная).
4. Ответ появляется в чате и **озвучивается** встроенным синтезатором речи часов (офлайн, русский голос поддерживается).

Также можно набирать/диктовать текст обычным полем ввода (watchOS сама предложит диктовку, клавиатуру или ввод с iPhone).

## Требования

- Apple Watch с **watchOS 10+** (Series 9/10/Ultra — идеально, поддерживаются все последние модели).
- Mac с **Xcode 16+** для сборки и установки. Без Mac установить приложение на часы, к сожалению, нельзя — так устроена экосистема Apple. Бесплатного Apple ID достаточно (аккаунт разработчика за $99 не нужен, но подпись придётся обновлять раз в 7 дней).
- Бесплатный API-ключ **Groq**: зарегистрируйся на [console.groq.com](https://console.groq.com/keys) и создай ключ (карта не нужна, лимитов бесплатного тарифа хватает с запасом).

> ⚠️ Не путать: **Groq** (groq.com) — это бесплатный и очень быстрый хостинг открытых моделей. **Grok** (x.ai, Илон Маск) — платный API без бесплатного тарифа. Приложение по умолчанию использует Groq, но в настройках можно указать любой OpenAI-совместимый сервер, включая `https://api.x.ai/v1`.

## Установка

1. Открой `WristAI/WristAI.xcodeproj` в Xcode.
2. В настройках таргета (**Signing & Capabilities**) выбери свою команду (Team) — свой Apple ID.
3. При желании впиши API-ключ в `Secrets.swift`, чтобы не вводить его на часах.
4. Подключи iPhone (с сопряжёнными часами) к Mac кабелем, выбери свои часы как устройство запуска и нажми **Run** (⌘R). Часы должны быть разблокированы и на зарядке либо на руке.
5. При первом запуске разреши доступ к микрофону.

Если ключ не вписан в `Secrets.swift` — открой настройки в приложении (шестерёнка) и введи его в поле «API-ключ» (проще всего через «Ввод с iPhone», watchOS предложит сама).

## Настройки в приложении

- **API-ключ** — ключ Groq (или другого сервера).
- **Модель** — Llama 3.3 70B (умнее) / Llama 3.1 8B (быстрее) / GPT-OSS 120B.
- **Озвучивать голосом** — вкл/выкл голосовые ответы.
- **Base URL** — адрес любого OpenAI-совместимого API. Сюда можно подставить свой сервер (вариант «свой бэкенд»): он должен реализовать `POST /chat/completions` и `POST /audio/transcriptions` в формате OpenAI.

## Структура кода

| Файл | Назначение |
|------|-----------|
| `WristAIApp.swift` | Точка входа |
| `ContentView.swift` | Экран чата: пузыри сообщений, поле ввода, кнопка записи |
| `SettingsView.swift` | Настройки (ключ, модель, озвучка, свой сервер) |
| `ChatViewModel.swift` | Логика чата: история, отправка, обработка ошибок |
| `GroqClient.swift` | HTTP-клиент: chat completions + Whisper (multipart) |
| `AudioRecorder.swift` | Запись с микрофона (AAC 16 кГц моно) |
| `Speaker.swift` | Озвучка ответов (AVSpeechSynthesizer, ru/en автоматически) |
| `Secrets.swift` | Место для API-ключа при сборке |
