## 🇷🇺 Русская версия

🎮 Я сделал свой собственный Game Pass.

Не подписку от Microsoft — а бота, в котором собраны все мои игры в одном месте.

Идея простая: я делаю игры как pet-проекты, и они разбросаны по репозиториям и ссылкам. Захотел показать кому-то — начинается «подожди, сейчас найду ссылку». Надоело.

Теперь всё иначе: открываешь бота → видишь каталог моих игр → выбираешь → играешь. Свой личный Game Pass, только бесплатный 😄

Что внутри уже сейчас:

⚔️ Jedi Deflector — браузерный bullet-hell, где световой меч сам отбивает лазеры обратно во врагов. Неон, киберпанк, волны дроидов и система прокачки.

…и это только начало — каждый новый проект будет сразу появляться в каталоге.

✅ Собирать полноценную игру на чистом JS/Canvas — без движка и без билда
✅ Проектировать каталог так, чтобы добавление новой игры занимало минуты
✅ Доводить pet-проекты до состояния «можно показать людям», а не «лежит в столе»

## 🇬🇧 English version

🎮 I built my own Game Pass.

Not the Microsoft subscription — a bot that gathers all my games in one place.

The idea is simple: I build games as side projects, and they end up scattered across repos and links. Every time I wanted to show one to someone, it turned into "hold on, let me find the link." I got tired of that.

Now it works like this: open the bot → browse my game catalog → pick one → play. My personal Game Pass, except it's free 😄

What's inside so far:

⚔️ Jedi Deflector — a browser-based bullet-hell where your lightsaber auto-deflects laser bolts back at enemies. Neon cyberpunk visuals, waves of droids, and a roguelike upgrade system.

…and this is just the start — every new project lands in the catalog right away.

What I learned along the way:
✅ Shipping a complete game in pure JS/Canvas — no engine, no build step
✅ Designing the catalog so adding a new game takes minutes, not hours
✅ Pushing side projects to a "show it to people" state instead of letting them collect dust
